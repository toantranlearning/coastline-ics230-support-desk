A portal page contains a heading, a customer's name, and a total. The browser displays those items, but PHP may have calculated and assembled them on the server first. To review that code, you need to recognize which statements read a value, which decide whether to continue, and which produce output.

This companion introduces the PHP used in the M01 security lecture. The security lecture explains why the controls matter. Here you practice reading the language that implements them. Environment setup and editor commands remain in the Orientation lab guide.

★Follow execution, not only the function names

For each example, identify the starting value, the statement that uses it, and the resulting output or branch. A function can behave exactly as documented while the surrounding program enforces the wrong rule.

1Separate PHP on the server from HTML in the browser

PHP executes on the server. Its output becomes part of the HTTP response sent to the browser. HTML describes the page the browser should create; it does not execute PHP. A file can contain both languages.

PHP
<?php
$heading = 'Equipment checkout';
?>
<h2><?= $heading ?></h2>
Output
<h2>Equipment checkout</h2>

<?php enters PHP mode, and ?> leaves it. Outside those tags, the HTML passes into the output. <?= $heading ?> is a short echo tag: it writes the value of the expression at that position. In the browser, the resulting <h2> creates a heading displaying Equipment checkout. The browser receives that HTML, rather than the variable assignment.

The value above is fixed text written by the developer. An output expression containing outside data needs the context-specific protection taught in the security lecture. A short echo tag does not apply encoding automatically.

iA heading edit and a PHP edit affect different instructions

Changing the words between <h2> and </h2> changes HTML content. Changing $heading changes the PHP value used to produce content. Save and reload to observe the response, because editing a source file does not alter a page already loaded in the browser.

Source: PHP escaping from HTML (opens in a new tab) explains mixed templates and short echo tags.

2Read variables, assignments, and strings

A variable name begins with $. = assigns the value on its right to the variable on its left. A semicolon ends a statement. Quotes identify a string, which is a sequence of bytes used here to represent text.

PHP
<?php
$item = 'Loan kit';
$item = 'Camera kit';
echo $item . "\n";
Output
Camera kit

The first assignment stores Loan kit. The second replaces that value with Camera kit. echo writes output, and the dot . joins strings. "\n" contains a newline because it is double-quoted. A newline in the source file alone does not cause a newline in the output.

Single-quoted strings preserve most characters literally. Double-quoted strings interpret escapes such as \n and can include variable values. Comments beginning with // continue to the end of the line and explain code without executing.

PHP
<?php
$name = 'Avery';
echo "Hello, $name\n";
echo 'Hello, $name' . "\n";
Output
Hello, Avery
Hello, $name

◆Expression and statement

An expression produces a value, such as $item . "\n". A statement performs a step, such as assigning that value or writing it with echo. PHP evaluates the expression before the statement uses its result.

Source: PHP strings (opens in a new tab) documents quotes, escapes, and variable interpolation; PHP assignment operators (opens in a new tab) explains assigning values.

3Recognize types and arithmetic

Values have types. An integer is a whole number, a float represents a number with a fractional part, a Boolean is true or false, and null represents no value. A string that contains digits is still a string until an operation interprets or converts it.

PHP
<?php
$quantity = 2;
$price = 49.99;
$total = $quantity * $price;
printf("Total due: %.2f\n", $total);
var_dump($quantity);
var_dump('2');
Output
Total due: 99.98
int(2)
string(1) "2"

* multiplies. printf is a function that formats and writes output. Its first argument is a format string; %.2f writes a number with two digits after the decimal point. The second argument supplies the value for that placeholder. var_dump displays a value's type and content, which helps you investigate comparisons.

The lecture's price example illustrates an input rule. Floating-point arithmetic is not a general recommendation for accounting systems; representing money needs a deliberate precision and rounding policy.

Source: PHP types (opens in a new tab) introduces types; PHP printf (opens in a new tab) defines its format placeholders.

4Distinguish conversion from validation

A cast requests a type conversion. (int)$value converts a value to an integer. It does not ask whether the value satisfies a business rule.

✕PHPVulnerable
<?php
// WHY: Converting to an integer still permits a negative quantity.
$raw = '-5';
$quantity = (int)$raw;
echo $quantity . "\n";

Vulnerable. Why: Converting to an integer still permits a negative quantity.

Output
-5

The cast succeeds, but a checkout that accepts only positive quantities must still reject this value. Conversion answers a representation question; validation decides whether the value is acceptable.

For a local practice value, filter_var can check integer representation. It returns the integer on success and false when the value fails this filter.

PHP
<?php
var_dump(filter_var('2', FILTER_VALIDATE_INT));
var_dump(filter_var('two', FILTER_VALIDATE_INT));
Output
int(2)
bool(false)

FILTER_VALIDATE_INT is a named constant supplied by PHP. Constants do not use a $ prefix. The function's arguments are the value to inspect and the filter to apply.

!A valid integer may still violate the rule

Follow a representation check with the allowed range check because -5 and 5000 can be integers while remaining unacceptable quantities.

Source: PHP integer conversion (opens in a new tab) describes casts; PHP filter_var (opens in a new tab) describes filtering local values.

5Read array entries and request data

An array stores entries identified by keys. In the following example, => associates a key with a value, and square brackets select an entry.

PHP
<?php
$fields = ['item' => 'Loan kit', 'quantity' => '2'];
echo $fields['item'] . "\n";
$missing = $fields['unknown'] ?? null;
var_dump($missing);
Output
Loan kit
NULL

?? is the null coalescing operator. It selects the value on the left when that entry exists and is not null; otherwise it selects the expression on the right. Here, the absent key produces the default null. A default does not check a supplied value.

PHP supplies request arrays called superglobals, which are available across scopes. $_GET contains parsed query parameters. $_POST contains parsed form-body fields for supported form content types. $_COOKIE contains cookie values supplied with the request. Their names do not mean the values are trustworthy.

PHP
<?php
$displayName = $_POST['display_name'] ?? null;

This is a web-handler fragment. Its value depends on an HTTP request, so it has no single standalone output. A form field ordinarily supplies text, but a caller can submit an array shape such as display_name[]=Avery. Check the expected type before using a string function.

Source: PHP arrays (opens in a new tab) explains entries; PHP superglobals (opens in a new tab) lists the request variables.

6Read comparisons and conditions

= assigns a value. === asks whether two values have identical types and values. !== asks whether they are not identical. == permits type conversion in some comparisons.

PHP
<?php
$value = '2';
var_dump($value === 2);
var_dump($value == 2);
var_dump($value !== 2);
Output
bool(false)
bool(true)
bool(true)

An if executes its block when the condition is true. Braces group the statements belonging to the block. An else supplies the alternative when the condition is false.

✓PHPSecure
<?php
// WHY: Only the explicitly permitted role enters this branch; an absent role is refused.
$role = null;
if ($role === 'admin') {
    echo "Admin operation allowed.\n";
} else {
    echo "Operation refused.\n";
}

Secure. Why: Only the explicitly permitted role enters this branch; an absent role is refused.

Output
Operation refused.

With $role = 'admin';, the condition is true and the other message appears. With null, 'customer', or an unexpected string, it is false. This example illustrates fail-closed branching, rather than a complete authorization implementation.

★Trace the value through the condition

Ask what happens for the intended value, an unexpected value, and a failure value. A negative test such as “role is not customer” can admit an absent role, because absence is also different from customer.

Source: PHP comparisons (opens in a new tab) defines comparison behavior; PHP if (opens in a new tab) explains conditional execution.

7Combine conditions without calling the wrong operation

|| means logical OR: either side being true makes the result true. && means logical AND: both sides must be true. ! means NOT, which reverses a Boolean result. < and > compare sizes.

✓PHPSecure
<?php
// WHY: The type check runs first, so a string function never receives this array.
$value = ['Loan kit'];
if (!is_string($value) || strlen($value) > 80) {
    echo "Invalid text.\n";
} else {
    echo "Text accepted.\n";
}

Secure. Why: The type check runs first, so a string function never receives this array.

Output
Invalid text.

is_string returns true for a string and false otherwise. The ! makes the first condition true for this array. PHP then skips strlen, because the OR result is already true. This is short-circuit evaluation. For AND, a false left operand means PHP skips the right operand.

strlen counts bytes. The main lecture uses mb_strlen($value, 'UTF-8') to count characters for UTF-8 text, with the mbstring extension. ASCII text has the same byte and character count; many other characters do not. Match the measurement to the field's rule.

✓Put the prerequisite first

Check the type before measuring or transforming text because a caller can submit a different shape from the form's expected string. Short-circuit conditions can preserve that execution order.

Source: PHP logical operators (opens in a new tab) describes short-circuit behavior; PHP mb_strlen (opens in a new tab) describes character counting.

8Understand function arguments and returns

A function is a named operation. A call uses parentheses to pass arguments. A return value is the result the call gives back. Assigning the returned value stores it for later statements.

PHP
<?php
function add_tax(float $subtotal): float
{
    return $subtotal * 1.10;
}
$total = add_tax(20.00);
printf("%.2f\n", $total);
Output
22.00

function defines the operation. $subtotal is its parameter, the name used inside the function for the supplied argument. float declares the expected numeric type, and : float declares the returned type. return ends that call and gives its expression's value back to the caller. Type declarations do not establish business rules such as a permitted price range.

Functions named save_display_name, lookup_role, and show_admin_page in the security lecture represent application operations. They are not PHP built-ins. Read their stated contracts to understand the example; copying a fragment without those functions does not create a complete program.

Source: PHP user-defined functions (opens in a new tab) describes definitions and parameters; PHP type declarations (opens in a new tab) explains declared types.

9Read filter_input in an HTTP handler

The main lecture reads a submitted quantity with filter_input. Its arguments select the request input, the field name, and the filter.

✓PHPSecure
<?php
// WHY: Specific failure checks and a range rule keep invalid quantities from reaching the calculation.
$quantity = filter_input(INPUT_POST, 'quantity', FILTER_VALIDATE_INT);
if ($quantity === false || $quantity === null || $quantity < 1 || $quantity > 25) {
    http_response_code(400);
    exit('Quantity must be a whole number from 1 to 25');
}
echo 'Accepted quantity: ' . $quantity;

Secure. Why: Specific failure checks and a range rule keep invalid quantities from reaching the calculation.

This is a web-handler fragment. The following table describes its outcomes for the supplied request fields.

INPUT_POST selects POST input. With these default options, invalid integer input returns false, and a missing field returns null. The range checks then enforce 1 through 25. http_response_code(400) sets the response status; exit writes its optional message and stops the script. Setting a status alone does not stop execution.

iLocal data does not create an HTTP request

filter_input reads the original request input. Assigning a value to $_POST in a standalone practice script does not supply that original input. Use the earlier filter_var example to practice with local values, because the two functions read different sources.

10Read output encoding and flags

The language operation echo writes a value without deciding whether that value should be HTML. htmlspecialchars returns a representation suitable for HTML text and ordinary quoted HTML attributes.

✓PHPSecure
<?php
// WHY: HTML encoding keeps the supplied brackets from creating an HTML element in page text.
$label = '<b>Loan kit</b>';
$encoded = htmlspecialchars($label, ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
echo $encoded . "\n";

Secure. Why: HTML encoding keeps the supplied brackets from creating an HTML element in page text.

Output
&lt;b&gt;Loan kit&lt;/b&gt;

The browser shows the literal text <b>Loan kit</b> when this output appears in HTML page text. The function arguments specify the original string, the options, and its encoding. ENT_QUOTES includes both quote types. ENT_SUBSTITUTE handles invalid encoding sequences by replacement. The single | combines option bits; it is bitwise OR and differs from logical OR ||.

✕This function is not a universal destination control

Do not use HTML encoding as proof of SQL or JavaScript safety because those languages interpret different syntax. The security lecture teaches the destination decision; this example shows the PHP call that implements one HTML case.

Source: PHP htmlspecialchars (opens in a new tab) defines conversions and flags.

11Recognize session state and included files

Ordinary local variables do not automatically carry over into another HTTP request. PHP's session mechanism can retrieve saved state using a session identifier. After session_start() opens or resumes a session, $_SESSION contains its stored entries.

PHP
<?php
session_start();
$currentUserId = $_SESSION['user_id'] ?? null;

This web fragment reads a session entry if it exists. It does not authenticate a password, authorize an operation, or establish that the user intended a request. Those are distinct security decisions. The browser sends an eligible session cookie according to its delivery rules, and PHP uses its identifier to find the session.

require_once loads another PHP file and ensures it is included only once in the current execution. A portal file may use it to obtain shared functions or initialize common behavior.

PHP
<?php
require_once __DIR__ . '/shared.php';

__DIR__ is a magic constant containing the directory of the current file. The dot joins it with the relative filename. This fragment requires that shared.php actually exist at that location, so it is not a standalone exercise. A missing required file stops successful execution rather than silently supplying the expected helpers.

!Read the included behavior too

Review the shared file when a security decision depends on it because a function call or include can hide the check you are trying to locate. A filename such as auth.php does not by itself prove that a particular operation is authorized.

Source: PHP session basics (opens in a new tab) explains session state; PHP require_once (opens in a new tab) explains inclusion.

12Locate runtime configuration

getenv reads an environment variable. It returns a string when present and false when absent. The security lecture explains why an API key should not be written into source code.

✓PHPSecure
<?php
// WHY: A missing secret stops the operation instead of selecting a shared default credential.
$apiKey = getenv('TECHCORP_API_KEY');
if ($apiKey === false || $apiKey === '') {
    http_response_code(500);
    exit('Server configuration error');
}

Secure. Why: A missing secret stops the operation instead of selecting a shared default credential.

This fragment's result depends on the server environment. It deliberately does not print the key. Reading a variable does not itself manage rotation, access permissions, or deployment secrecy; those are surrounding system responsibilities.

↗Look up the contract when a return value is unclear

The PHP Manual (opens in a new tab) documents arguments, return types, and failure behavior. Use that contract to trace the branch, because treating every false-looking result as the same thing can hide a valid zero or a missing value.

Source: PHP getenv (opens in a new tab) defines its return behavior.
