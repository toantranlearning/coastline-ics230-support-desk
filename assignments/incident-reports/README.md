# Incident-report starters

These course-specific Markdown starters follow the Canvas assignments. They are a teaching adaptation informed by NIST incident-response guidance, not official NIST forms or completed reports.

Copy the assigned starter into `reports/`; edit the copy and submit it to Canvas. Keep supplied case facts distinct from observations you make in the lab. Only complete the sections and checks your assignment requests. The prompts increase in depth across the course; preserve each incident as its own report and reference earlier cases when relevant.
